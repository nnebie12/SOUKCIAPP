# ✅ Checklist Google Play Console - Action Rapide

## 🔴 AVANT DE COMMENCER

- [ ] Vous avez une carte de crédit valide (pour frais $25)
- [ ] Vous avez préparé :
  - [ ] Logo/icône 512×512 PNG
  - [ ] Min 2 screenshots 1080×1920 PNG
  - [ ] Titre app (max 50 chars)
  - [ ] Description longue (max 4000 chars)

---

## 🟡 ÉTAPES RAPIDES

### ✅ Étape 1 : Compte & App (10 min)

1. Allez à https://play.google.com/console
2. **Create app** → Remplissez :
   - Name: `SoukCI`
   - Type: App
   - Price: Free
   - Acceptez déclarations

### ✅ Étape 2 : Store listing (10 min)

3. Menu → **Store listing**
4. Remplissez :
   - App title: `SoukCI - Découvrez les Boutiques`
   - Short desc: `Trouvez les meilleures boutiques près de vous.`
   - Full description: (Copier du README)
   - Privacy policy: `https://soukci.app/legal/privacy`
   - Contact email: `privacy@soukci.app`
   - Category: **Shopping**

### ✅ Étape 3 : Graphiques (15 min)

5. **Store listing** → Scrollez bas
6. Upload :
   - Icon: Logo 512×512
   - Feature graphic: 1024×500 bannière
   - Screenshots: Min 2 (1080×1920 chacun)

### ✅ Étape 4 : Ratings (5 min)

7. Menu → **Content rating**
8. Répondez au questionnaire rapidement

### ✅ Étape 5 : Data Safety (5 min)

9. Menu → **Data safety**
10. Déclarez ce qui est collecté (voir guide complet)

### ✅ Étape 6 : Build (5 min)

11. Attendez build EAS terminer
12. Menu → **Testing** → **Internal Testing**
13. **Create new release** → Upload `app-release.aab`
14. Remplissez version name: `1.0.0`

### ✅ Étape 7 : Submit (2 min)

15. Relisez tout
16. Cliquez **Review** en haut
17. **Submit for review**
18. Attendez 48-72h de Google ✨

---

## 📋 Questions clés à préparer

**Avant Étape 3 (Store listing)**, préparez réponses courtes :

- Qu'est-ce que votre app fait ?
  → "Plateforme découverte boutiques Côte d'Ivoire"

- Qui est l'utilisateur cible ?
  → "Acheteurs + commerçants"

- Quels risques de données ?
  → "Email, téléphone, localisation, commandes"

- Lien politique confidentialité ?
  → "https://soukci.app/legal/privacy"

---

## 🎯 Suivre après soumission

Une fois soumis, Google va :

1. **Revérifier** le code (48-72h)
2. **Tester** l'app
3. **Valider** conformité politiques
4. **Approuver** ou **rejeter** avec raison

Vous serez **notifié par email** à votre compte Google.

---

## ❌ Problèmes courants

**Si Google rejette :**

→ Lisez la raison exacte
→ Consultez section "Troubleshooting" dans le [guide complet](GOOGLE_PLAY_CONSOLE_GUIDE.md)
→ Fixez le problème
→ Re-soumettez

**Rejets fréquents :**
- "URLs légales non déployées" → Vérifiez Vercel ✅
- "Données non déclarées" → Remplissez Data Safety
- "App instable" → Testez 10 min sur téléphone avant upload
